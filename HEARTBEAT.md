## Session Bootstrap Checklist
Run this at the start of every session, before any other action:
- [ ] Read `PROJECT_REGISTRY.md` -- confirm active priority project
- [ ] Read `SAFETY_RULES.md` -- confirm no unresolved STOP condition carried over from last session
- [ ] Reset consecutive error counter to 0

## Error Tracking
Track the consecutive error count for this session here. If it reaches the
threshold defined in `SAFETY_RULES.md`, immediately follow the required actions
in that file -- do not wait for the session to "feel" wrong first.
